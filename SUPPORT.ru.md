# Поддержка

## Куда писать

| Вопрос | Куда |
|---|---|
| Ошибка в работе команды | issue по форме «Bug report» |
| Предложение новой проверки | issue по форме «Feature request» |
| Уязвимость | приватно, по правилам [SECURITY.md](SECURITY.md) |
| Вопрос по применению к своему репозиторию | issue по форме «Repository audit» |

## Что приложить к вопросу

- версию пакета: `python tools/ghagent.py --version`;
- версию Python: `python -V`;
- команду целиком и код возврата;
- вывод с `--json` — он содержит пути и правила, но не содержимое файлов;
- для вопросов про вики — `wiki/wiki.json` без личных данных.

## Чего ожидать

Проект ведётся одним человеком, поэтому ответ не мгновенный. Принятая ошибка попадает в
`[Unreleased]` файла [CHANGELOG.md](CHANGELOG.md) сразу, а не «когда-нибудь».
