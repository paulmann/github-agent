# Code of conduct

## Our commitment

This project adopts the [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The text at that link is part of this document: it describes expected
behaviour, examples of unacceptable behaviour, the maintainer's responsibilities and the
enforcement ladder.

In short, in our own words:

- discuss the code and its behaviour, not the person;
- criticism carries a verifiable fact: a command, a file, a line, an output;
- insults, harassment and publishing someone else's personal data are not acceptable;
- technical disagreements are settled by a measurement, not by volume.

## Scope

This code applies in issues, pull requests, discussions and the wiki of this repository, and
anywhere a person acts on behalf of the project.

## Reporting

Report a violation privately: through the owner's profile or the **Report abuse** control in the
GitHub interface. Reports are handled confidentially.

## Consequences

A violation leads to a warning, then to restricted participation, then to a ban. The maintainer
decides and communicates the reason privately.
