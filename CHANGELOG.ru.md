## [1.1.0] - 2026-10-24

### Добавлено

- `ghagent assets render|check|suggest` — собственные изображения репозитория: социальное превью 1280×640, отрисованное из метаданных проекта, векторный двойник для README и проверка формата, размера файла и пикселей, alt-текста и каждого упомянутого файла. Для PNG нужен Pillow; без него создаётся SVG, и отчёт прямо об этом говорит, а не делает вид, что превью готово.
- `skills/repo-images` — как выбрать и разместить баннер, социальное превью, скриншот и схему, вместе с ограничениями платформы, которые решают, годится ли изображение вообще.
- Двуязычная документация: английские файлы основные, русские копии несут суффикс `.ru.md`, включая страницы вики, которые получают отдельную группу навигации.
- 21 новая самопроверка отрисовки и проверки изображений, включая приманки: превью, спрятанное в `node_modules`, и файл больше 1 МБ.

### Изменено

- `audit` теперь оценивает баннер в README и социальное превью: репозиторий без картинки больше не проходит как полный.
- Проверка markdown предупреждает о картинках, загружаемых по незащищённому `http://`.

### Исправлено

- `wiki publish` сообщает `wiki.remote-missing` вместе с шагом платформы вместо падения на пуше, который не может создать вики-репозиторий.
- Числа в документации обновлены: 134 самопроверки, 13 команд, 11 модулей библиотеки, 15 ловушек платформы.

## [1.0.0] - 2026-10-24

### Добавлено

- `ghagent audit` — обязательные файлы, контракт README, контракт CHANGELOG и оценка гигиены; локальное дерево или удалённые метаданные через `gh api`.
- `ghagent doc` — гигиена UTF-8/BOM/CRLF, структура заголовков, таблицы, блоки кода, alerts, картинки, внутренние ссылки и якоря, согласованность оглавления, правила приватности.
- `ghagent wiki build|verify|publish|init` — вики по манифесту с `_Sidebar.md` и `_Footer.md`, переписывание ссылок под плоское пространство вики, сухой прогон публикации, сохраняющий чужие страницы.
- `ghagent changelog check|release|suggest|notes` — соответствие Keep a Changelog 2.0.0, перенос `[Unreleased]` со ссылками сравнения, черновик из conventional commits и текст релиза.
- `ghagent meta suggest|apply` — проверка описания и тем, слияние тем при записи через `PUT /repos/{owner}/{repo}/topics`.
- `ghagent install|verify-install|uninstall|snippet` — установка в каталог навыков агента с манифестом sha256, обнаружение расхождений и печать блока правил.
- `ghagent report` — один markdown-отчёт: гигиена, документы, журнал изменений, вики.
- 113 самопроверок с фикстурами на каждое правило, приманками для правил, которые должны молчать, и публикацией в песочнице на локальный bare-репозиторий.
- Пять навыков: `github-repo`, `github-wiki`, `changelog-release`, `contributing-and-community`, `import-to-agents`.

### Безопасность

- Пакет поставляется без токенов, абсолютных путей машины и личных адресов; правило приватности роняет сборку, если такое появится, а самопроверка следит за самим пакетом.
